# World map provenance

The Global Evidence Map (`src/components/map/world-map-data.ts`) is generated by
`scripts/generate-world-map.ts` (`npm run map:generate`).

- **Source:** [Natural Earth](https://www.naturalearthdata.com/) 1:110m Cultural Vectors,
  Admin 0 – Countries (`ne_110m_admin_0_countries.geojson`, via
  [nvkelso/natural-earth-vector](https://github.com/nvkelso/natural-earth-vector)).
- **License:** Public domain ([Natural Earth terms of use](https://www.naturalearthdata.com/about/terms-of-use/)).
  Attribution is not required; we credit it in the site footer anyway.
- **Processing:**
  1. Countries are grouped by Natural Earth's `CONTINENT` attribute.
  2. Russia is split at 60°E (approximate Ural boundary): west → Europe, east → Asia.
  3. French Guiana (overseas France) is assigned to South America.
  4. "Seven seas (open ocean)" territories are omitted.
  5. Vertices are projected with Equal Earth (d3-geo) and unioned per continent
     (polygon-clipping) so internal borders disappear.
- The raw GeoJSON is downloaded at generation time and is **not** committed.
  Only the derived path data is committed (~58 KB).

Continent groupings are a stylised simplification for navigation, not a geopolitical statement.
